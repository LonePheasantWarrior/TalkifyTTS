# 对话模式（Dialogue Mode）

## 功能概述

在 Talkify 原有「单一发音人」基础上新增旁白/对话双发音人：

- 总开关：关闭后保持原单音色行为，开启后按引号切分文本
- 本地切分，不依赖大模型自己识别角色
- 引号外使用「旁白发音人」，引号内使用「对话发音人」
- 分别发起合成请求，按顺序拼接音频返回系统 TTS
- 可选：是否朗读引号本身、段间静音停顿
- 旁白/对话可分别选择任意供应商与音色（MiMo / Azure / 腾讯 / 通义 / 豆包 / OpenAI / 本地 ZipVoice 等）
- 风格指令：仅对支持该配置项的供应商生效，其余供应商忽略
- 简单角色规则：人物名 / 正则 → 指定发音人
  - 优先级：`<<人物>>` 显式标记 > 角色规则 > 默认对话 > 默认旁白

## 实现要点

| 模块 | 说明 |
|---|---|
| `DialogueSegmenter` | 纯 Kotlin 引号状态机；支持 `“”「」『』‘’""`；嵌套只认最外层；未闭合保守并入对话；过滤纯标点段 |
| `DialogueSegmentResolver` | 段 → 发音人绑定；显式标记 > 规则 > 默认对话/旁白；非法正则安全回退 |
| `SynthesisParams` | 新增 `voiceIdOverride` / `styleInstructionOverride`，9 个 Provider 接线 |
| `TalkifyTtsService` | 逐段合成、`callback.start()` 仅一次、段间静音、采样率不一致时回退旁白、段供应商缓存 |
| `DataStoreDialogueModeRepository` | DataStore Preferences 持久化总开关/绑定/规则 |
| UI | 主界面对话模式入口卡片 → 设置页 + 两步式发音人选择器（供应商 → 音色 → 风格） |

## 开发说明

- 本功能由 **GLM-5.3** 辅助开发，消耗 **1200+ 积分**
- 后续「人物级分角色朗读」（NER / 人物池 / 逐人物音色）当前积分耗尽，待有积分后继续
- 本功能分支为 `feature/dialogue-mode`，基于上游 `main`，未包含 TalkifyC 的 applicationId/应用名改动；品牌化测试包在独立 `TalkifyC` 分支

## 已知限制

- 试听页仍为单音色，真实角色效果需在阅读软件中测试
- 混用采样率不同的供应商（如 MiniMax 32kHz 与其他 24kHz）时会自动回退旁白发音人，后续可加重采样支持
