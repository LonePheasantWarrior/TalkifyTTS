## 可再进一步的前沿方向（按性价比排序）

**1. M3 Expressive 动效系统全局接入 —— 零新依赖，性价比最高**
material3 1.4.0 已经在 `libs.versions.toml` 里，但多数 Expressive 能力大概率还没启用：
- **MotionScheme（expressive 弹簧物理）**：在 `Theme.kt` 一处接入，全局所有 `animate*AsState`、组件过渡自动换成带物理感的弹性曲线，动效质感提升立竿见影
- **新组件**：expressive 风格的加载指示器（`LoadingIndicator`，比转圈 CircularProgressIndicator 现代）、`FloatingToolbar`、`ButtonGroup`
- **形状变形**：`androidx.graphics:graphics-shapes` 的 `RoundedPolygon`（含官方 MaterialShapes 造型库），可做选中态形状渐变形、FAB 变形
- **波浪线（squiggly）进度条**：和你“合成中/模型下载中”的场景天然契合

**2. 共享元素过渡（SharedTransitionLayout）—— 导航级现代感提升最明显的一项**
Compose 1.7+ 稳定 API，Navigation Compose 2.9 原生支持。典型落点：
- 主界面点 "Talkify" 标题进关于页 → 标题连续变形而非跳变（`sharedBounds`）
- 供应商卡片 → `ConfigBottomSheet` 内对应条目的元素接力

**3. AGSL RuntimeShader 音频反应式视觉 —— 最前沿，且最契合 TTS 品牌**
API 33+ 的 GPU 着色器（`RuntimeShader` + `graphicsLayer.renderEffect`）。Talkify 预览播放本来就有完整 PCM 流，用真实振幅驱动 shader 做**液体波形光晕/流动背景**，替代静态的 EqualizerBars，是“用声音本身作画”。minSdk 30 需按 API 33 分支、降级回现有 EqualizerBars。工作量中等偏高，但这是安卓 UI 当前真正的技术前沿。

**4. Rive 状态机动画 —— 3 的低门槛替代**
单个 .riv 文件承载“空闲 → 合成中 → 朗读中”状态机，交互可驱动，比 Lottie 逐帧高级。代价是新增依赖和资产管线。

**5. 实时模糊玻璃（Haze 或 RenderEffect）**
遵循你的克制原则：仅把现有浮层（顶栏/Sheet/Dialog）从“半透明色”升级为 API 31+ 实时背景模糊，minSdk 30 降级保半透明。

**6. 看不见但体感强的一层：Baseline Profile**
动画再好，掉帧就全毁。加 baseline profile 可显著改善冷启动和首屏帧率，让 120Hz 设备上动效真正丝滑。

## 我的推荐

**先做 1 + 2**（都是现有依赖内的 API，一两天的量级，全局质感立刻上一个台阶）；**3 作为品牌亮点放二期**——它是唯一能让 Talkify 在同类 TTS 应用里“一眼不同”的技术。主要权衡：3、5 需要按 API 等级做优雅降级，且要守住你的浮层克制原则，别让玻璃和着色器铺满全屏。
